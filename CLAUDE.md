Use Bun, not Node: `bun install`, `bun test`, `bun run dev`, `bun run build`.

This repo is a Vite + React SPA. Progress is IndexedDB (Dexie). Live catalog and portraits come from Data Dragon. Arena tiers come from OP.GG. Do not add a Node server, Next.js, or a Riot API key.

Do not commit `.env`, `data/*.json`, or sqlite files under `data/`.
